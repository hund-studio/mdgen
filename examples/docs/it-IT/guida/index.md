# Guida

Questa cartella contiene un `index.md`: nella sidebar la voce **Guida** è
cliccabile e apre _questa_ pagina (oltre a espandere la sezione). Per
espandere/comprimere la sezione **senza** cambiare pagina, usa la freccia
(caret) a destra della voce.
