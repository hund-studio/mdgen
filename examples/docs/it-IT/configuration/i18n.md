# Siti multilingua (i18n)

Dichiara i tuoi `locales` in `config.json` e metti ogni lingua in una cartella
con il nome del locale, **condividendo la stessa struttura** (stessi nomi di
file e cartelle, contenuto tradotto):

```
le-mie-docs/
├─ .mdgen/config.json     # { "locales": ["it-IT","en-US"], "defaultLocale": "it-IT" }
├─ it-IT/
│  ├─ index.md
│  └─ guide/index.md
└─ en-US/
   ├─ index.md
   └─ guide/index.md
```

## Cosa ottieni

- Un **selettore di lingua** nella sidebar che mostra il nome nativo di ogni
  lingua.
- Sidebar, indice di ricerca e routing **per locale** (`/<locale>/…`).
- Un **redirect dalla radice** che sceglie la lingua migliore in base a
  `navigator.language` del visitatore, con fallback su `defaultLocale`.
- Se una pagina manca in un'altra lingua, il selettore **disabilita** quella
  lingua per quella pagina (niente link rotti).

> **Suggerimento:** mantieni **identici** i nomi di file e cartelle tra i locale
> (traduci il _contenuto_, non i nomi), così le pagine equivalenti si mappano tra
> loro. Questa stessa documentazione è organizzata esattamente così.

## Solo via CLI

L'i18n richiede un passo di build, quindi è disponibile solo con la
[CLI](../cli.md), non con lo strumento web.
